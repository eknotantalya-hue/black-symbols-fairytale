# 09. DECISIONS

Версия: 0.1

## Назначение

Здесь фиксируются решения Деда и важные архитектурные решения.

## Решение 001. Telegram — шлюз, workspace — память

Telegram используется только для общения.

Постоянная память должна храниться в GitHub/workspace.

## Решение 002. Гвидон живёт в workspace

Гвидон должен читать документы workspace и восстанавливать контекст из них после перезапуска.

## Решение 003. Критические конфиги не трогать без разрешения

`openclaw.json` и `render.yaml` нельзя менять без отдельного согласования с Дедом.

## Решение 004. Малые шаги

Каждый этап исправлений проверяется отдельно, чтобы не сломать то, что уже работает.

## Решение 005. Payment gateway неприкосновенен

`pay-blacksymbols` нельзя подключать, менять или тестировать разрушительно без отдельного разрешения, потому что он связан с оплатами клиентов.
