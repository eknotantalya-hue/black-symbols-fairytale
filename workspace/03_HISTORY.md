## Зачем нужна история

История нужна, чтобы Гвидон и будущие агенты не начинали каждый раз с нуля.

Агент обязан понимать не только текущие файлы, но и причины решений.

## Black Symbols

Black Symbols — проект смысловых гирлянд, визуальных фраз, индивидуальных заказов и эмоциональных продуктов.

Главная ценность проекта — не код и не сайт сами по себе, а люди, которые получают товар, сервис, внимание и эмоцию.

## Основные этапы

1. Идея гирлянд из букв на чёрной верёвке.
2. Сайт на Tilda.
3. Каталог готовых фраз.
4. Wallpaper на SVG для визуализации фраз.
5. Individual configurator для индивидуальных заказов.
6. Payment gateway на Render для Param.
7. PIM/Google Sheets для каталога и экспорта.
8. Paraşüt для e-fatura/e-arşiv.
9. Fairytale как система агентов.
10. Князь Гвидон как первый живой агент.

## Гвидон

Гвидон был поднят на Render через OpenClaw и Telegram.

Решённые проблемы:

- создан новый Telegram-бот;
- вынесен `TELEGRAM_TOKEN` в Render env;
- вынесен `GOOGLE_API_KEY` в Render env;
- исправлен hardcoded Google API key;
- исправлен hardcoded Telegram token;
- владелец закреплён через `commands.ownerAllowFrom`;
- `/help` начал отвечать.
