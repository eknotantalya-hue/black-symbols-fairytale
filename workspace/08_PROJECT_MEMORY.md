# 08. PROJECT MEMORY

Версия: 0.1

## Назначение

Этот файл хранит устойчивую память проекта, которую агенты обязаны учитывать.

## Black Symbols

- Проект делает смысловые гирлянды и визуальные фразы.
- Главный приоритет — пользователи, качество товара, сервис, эмоции.
- Основной язык сайта — турецкий.
- Русский и английский — дополнительные.
- Tilda — основной сайт.
- Render — серверы и агенты.
- GitHub — код и память.

## Производство

- Буквы на чёрной верёвке.
- Стандартная высота символов: 8.5 см.
- `/` — реальный физический символ.
- `|` — технический разделитель строк, не физический символ.
- Все физические символы считаются в цене, кроме технического `|`.

## Сервисы

- `pay-blacksymbols` — платежи Param, не трогать без разрешения.
- `bs_wallpaper` — визуальная генерация на SVG.
- `bs_individual_configurator` — индивидуальный конфигуратор.
- `black-symbols-fairytale` — агенты.
- `black_symbols_state` — инфраструктурная память.
