# Предложения по изменению системы

Сюда попадают предложения:

- изменения Конституции;
- изменения законов;
- изменения архитектуры;
- создание новых агентов;
- изменение полномочий.

Формат:

PROPOSAL_YYYYMMDD_HHMM.md

Изменения никогда не применяются автоматически.
Сначала обсуждение.
Потом решение Деда.
Потом ручное внесение изменений.
