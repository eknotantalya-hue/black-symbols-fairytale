# Память агентов

Каждый агент имеет собственную память.

Примеры:

GVIDON_MEMORY.md
LEBED_MEMORY.md
BELKA_MEMORY.md
CHERNOMOR_MEMORY.md

Сюда записываются:

- уроки;
- ошибки;
- успешные решения;
- повторяющиеся проблемы;
- полезные наблюдения.

Удаление памяти запрещено.
Разрешено только архивирование.
