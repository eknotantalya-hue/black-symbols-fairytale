# Инциденты Fairytale

Сюда записываются:

- нарушения Конституции;
- опасные действия агентов;
- попытки удаления документов;
- утечки;
- ошибки безопасности;
- аварии.

Формат:

INCIDENT_0001_NAME.md

Каждый инцидент содержит:

- дату;
- участников;
- описание;
- доказательства;
- последствия;
- решение.
